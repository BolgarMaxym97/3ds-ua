# UniStore

`3ds-ua.unistore` is the Universal-Updater store for this project. Users add it once and
then install, update and remove the translation from the console, without taking the SD
card out.

Store URL (this is what goes into Universal-Updater → Settings → Select UniStore → Add):

```
https://raw.githubusercontent.com/BolgarMaxym97/3ds-ua/main/unistore/3ds-ua.unistore
```

Do not edit the file by hand — it is generated by `make unistore` from `tools/build.py`'s
`TITLES` and the version in `Makefile`, and checked by `make unistore-check`. The release
order matters: publish the GitHub release with its four archives **before** pushing a
regenerated store, or everyone who refreshes in between gets a download error. See the
"Випуск" section of `docs/internals.md`.
