## Кнопки й дії

Інфінітив: `Запустити`, `Видалити`, `Скопіювати`, `Створити`, `Відкрити`, `Закрити`, `Скасувати`, `Гаразд` (OK лишаємо `OK`), `Далі`, `Назад`, `Так` / `Ні`.

## Стиль

- звертання на «ви» з малої;
- «будь ласка» не додаємо, якщо його не було;
- лапки — «ялинки», тире — `—`, три точки — `…`;
- калькам з російської — ні: `настройки` → `налаштування`, `загрузка` → `завантаження`, `удалить` → `видалити`, `включить` → `увімкнути`, `подключение` → `з'єднання`/`підключення`, `сохранить` → `зберегти`, `текущий` → `поточний`, `следующий` → `наступний`, `коснитесь` → `торкніться`, `выберите` → `виберіть`;
- апостроф — ASCII `'` (U+02BC у шрифті немає).

## Технічні обмеження

- керуючі токени `{t:group.type:hex}` / `{/t:group.type}` — не чіпати, не переставляти, не додавати;
- підстановки `%d`, `%s`, `%1$s` — зберігати кількість і порядок;
- символи-глифи кнопок (`\ue000` = A, `\ue001` = B тощо) — зберігати;
- кількість переносів `\n` не більша за оригінал;
- ширина рядка в пікселях ≤ найширшої офіційної локалізації (перевіряє `validate.py`);
- жодних символів поза `assets/font_charset.txt`: `і→i`, `І→I`, `ї→ï`, `Ї→Ï`, `є→ε`, `Є→Ε`, `ґ→г` (робить `build.py` автоматично — у JSON пишемо **нормальною** українською).
