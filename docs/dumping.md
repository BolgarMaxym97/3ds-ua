# Як зняти дампи зі своєї консолі

*[In English](dumping.en.md)*

У репозиторії немає жодного файлу Nintendo. Щоб зібрати мод самому — або додати до нього
новий титул — потрібні дампи **зі своєї власної консолі**. Знімає їх GodMode9.

Користувачам, які просто ставлять готовий архів, це не потрібно: інструкції зі встановлення
в [README](../README.md).

---

## Перед початком

- встановлений GodMode9: `SD:/luma/payloads/GodMode9.firm` і папка `SD:/gm9/`
- у Luma `Enable game patching` стоїть `(x)`
- вільно щонайменше 2 ГБ на SD-карті (бекап NAND важить близько 1 ГБ)

Кнопки GodMode9: `A` вибрати або увійти, `B` назад, `Y` копіювати чи вставити, `X` видалити,
`SELECT` очистити буфер, `R`+`A` меню дій над файлом, `HOME` головне меню, `START`
перезавантаження, `R`+`L` знімок екрана.

Запуск: вимкнути консоль → тримати `START` → увімкнути → вибрати `GodMode9`.

## 1. Бекап NAND — обов'язково, один раз

1. `HOME` → `Scripts` → `GM9Megascript` → `Backup Options` → `SysNAND Backup` → `A`.
2. Чекати 10–20 хвилин. Результат: `0:/gm9/out/<дата>_sysnand_???.bin` і файл `.sha` поруч.
3. Скопіювати обидва файли з SD-карти на комп'ютер.

⚠️ Бекап NAND містить унікальні ключі вашої консолі (OTP, `movable.sed`). **Ніколи не
публікуйте його й не додавайте в git.** Єдину копію на SD-карті теж не тримайте — саме вона
рятує консоль, якщо щось піде не так.

## 2. Дамп romfs титулу

`romfs` — це те, де лежить перекладний текст.

Приклад для Меню HOME (EUR `0004003000009802`; USA `0004003000008F02`, JPN `0004003000008202`):

1. `[1:] SYSNAND CTRNAND` → `title` → `00040030` → `00009802` → `content`
2. Взяти **найбільший `.app`** — це поточна версія титулу. Менші — старі.
3. `A` → `NCCH image options...` → `Mount image to drive`
4. У змонтованому образі видно `romfs/`, `exefs/`, `exheader.bin`
5. Курсор на **`romfs`**, всередину не заходити → `Y` (копіювати)
6. `B` до списку дисків → `[0:] SDCARD` → `gm9` → `out`
7. **Створити папку з іменем титулу:** `R`+`A` на порожньому місці → `New folder` → набрати
   `0004003000009802` → `A`
8. Зайти в неї → `Y` (вставити), дочекатися копіювання
9. `B` назад до `[1:] SYSNAND CTRNAND` і повторити з пункту 1 для наступного титулу

**Пункт 7 не пропускайте.** Якщо копіювати все просто в `gm9/out`, папки назвуться `romfs`,
`romfs2`, `romfs3` — і потім не розібрати, де що.

⚠️ Застосунки лежать у гілці `00040010`, апплети — у `00040030`. Клавіатура, Посібник,
Список друзів, Меню HOME — апплети; Налаштування системи, Камера, Журнал дій — застосунки.

## 3. Дамп `code` + `exheader` — перевірка LayeredFS

Потрібен `tools/layeredfs_check.py`, який наперед скаже, чи зможе Luma під'єднати LayeredFS
до титулу. Це не формальність: якщо покласти папку `romfs` для титулу, який Luma гакати не
вміє, **кожен його запуск перетворюється на екран помилки**.

1. Змонтувати `.app` титулу, як у кроці 2.
2. Курсор на `.app` → `A` → `NCCH image options...` → **`Extract .code`**. GodMode9 сам
   розпакує BLZ і покладе файл у `0:/gm9/out/`.

   Саме `Extract .code`, а не копіювання `exefs/.code` вручну: вручну взятий файл може бути
   стисненим, і тоді сигнатури функцій у ньому не знайдуться.
3. У змонтованому образі скопіювати **`exthdr.bin`** у `0:/gm9/out/`.
4. Покласти обидва файли поруч із дампом romfs:

   ```
   work/0004003000009802/code.bin
   work/0004003000009802/exthdr.bin
   ```

   Імена жорстко не задані — чекер приймає `code.bin`, `*.code`, `code.dec.bin` і
   `exheader.bin`, `exthdr.bin`, `*.exthdr`. Важлива тільки папка `work/<TID>/`.

⚠️ Файли для різних титулів називаються однаково (`exthdr.bin`). Або перейменовуйте одразу
в GodMode9 (`R`+`A` → `Rename file`), або переносьте на ПК після кожного титулу.

### Перевірка самого чекера

Спершу два контрольні титули з відомою поведінкою на залізі:

```bash
python3 tools/layeredfs_check.py work/0004003000009802   # очікуємо: LayeredFS OK
python3 tools/layeredfs_check.py work/000400300000D002   # очікуємо: LOADER WOULD CRASH
```

Меню HOME на консолі працює, клавіатура сама по собі крешить. Якщо чекер збігся на обох —
йому можна вірити щодо решти. Без аргументів він обходить усі папки в `work/`:

```
=== 0004001000022200
  code.bin + exthdr.bin: 1234560 bytes (already decompressed), text 987654, ro 12345, data 6789
    fsMountArchive       0x0012A4
    fsRegisterArchive    NOT FOUND
    fsTryOpenFile        0x0031C8
    fsOpenFileDirectly   0x004A10
    fsUnmountArchive     0x005C88
    payload space        ok
    path string space    ok   (payload via .text padding, path via .rodata padding)
  -> LOADER WOULD CRASH - mark blocked
```

Рядок `NOT FOUND` показує, якої саме умови не вистачило.

Якщо чекер розійшовся з реальністю — [відкрийте Issue](../../../issues) з його виводом і з тим,
що насправді робить консоль. Інструмент, який помиляється, гірший за його відсутність.

## 4. Дамп системного шрифту

Потрібен для таблиць символів і ширин, без нього не працює `make validate`.

1. `[1:] SYSNAND CTRNAND` → `title` → `0004009b` → `00014002` → `content` → найбільший `.app`
2. `A` → `NCCH image options...` → `Mount image to drive` → скопіювати `romfs` у `0:/gm9/out`
3. На комп'ютері покласти файл як `work/0004009B00014002/cbf_std.bcfnt.lz`

## 5. Перенесення на комп'ютер і перевірка

`START` (перезавантаження) → вимкнути консоль → SD у комп'ютер:

```bash
cp -R /Volumes/<SD>/gm9/out/00040* work/
```

Має вийти `work/<TID>/romfs/…` — саме така вкладеність, без зайвого рівня. Далі:

```bash
python3 tools/dumpinfo.py work
```

Для кожного дампу покаже мовні папки, файли повідомлень і кількість рядків:

```
=== 000400300000D002  (512 KiB)
  message/  languages: 8
    EU_Dutch, EU_English, ...
    EU_English/swkbd_msbt_LZ.bin: 214 strings
    -> 214 translatable strings
```

Що має насторожити:

| Симптом | Причина |
|---|---|
| `no romfs/ inside` | скопіювався не той рівень — перевірте вкладеність папок |
| `no message*/ folders` | текст цього титулу лежить не в `message/` — так буває (Ігрові записи, Камера, Face Raiders), дивіться вміст romfs вручну |
| `!! no English folder` | дамп не того регіону |
| мовних папок 1–2 замість 8 | узято не найбільший `.app`, тобто стара версія титулу |
| `0 KiB` або дуже мало | копіювання обірвалось, повторіть |

Назва мовної папки залежить від титулу: у Меню HOME це `EU_Russian`, у Посібника —
`EU_Russia` без `n`. Перевіряйте для кожного окремо.

Швидка перевірка шрифту:

```bash
python3 tools/lz11.py work/0004009B00014002/cbf_std.bcfnt.lz   # має вивести магію b'CFNT'
```

## 6. Збірка

```bash
make font       # шрифт → assets/font_charset.txt + font_widths.json
make extract    # romfs → src/strings/*.json (наявні переклади зберігаються)
make validate   # перевірка: символи, ширина, кількість рядків, теги
make build      # → dist/luma/titles/...
make package    # → 3ds-ua-<версія>.zip
```

Потрібен Python 3.11+, зовнішніх залежностей немає.

## Місце на SD

Дампи разом важать до ~50 МБ (найбільший — Налаштування системи). Якщо місця бракує,
видаліть з `gm9/out` бекап NAND — він уже має бути на комп'ютері.
