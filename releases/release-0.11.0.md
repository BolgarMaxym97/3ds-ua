# 3DS UA 🇺🇦

Український інтерфейс для Nintendo 3DS. Мод займає місце російської мови в консолі: вибираєте в налаштуваннях «Українська» — і система говорить українською. Англійська та решта мов лишаються недоторканими, файли самої консолі не змінюються.

**Що нового в 0.11.0**

Дев'ять нових електронних довідників — тих, що відкриваються кнопкою «Довідник» у меню HOME.

- **Журнал дій**, **Гра по завантаженню**, **Nintendo 3DS Камера**, **Nintendo 3DS Звук**, **Mii Maker**, **Площа StreetPass Mii**, **Nintendo eShop**, **Face Raiders**, **AR Games** — усі дев'ять перекладено, разом 2403 абзаци. Кожен перевірено на консолі.

Разом з тими, що були в 0.10.0 (Інтернет-браузер і Налаштування системи), — **одинадцять довідників**. Над кожною сторінкою стоїть українська назва додатка, а в перемикачі мови документа є пункт **Українська**.

Терміни в кожному довіднику взято з самого додатка, а не з російського тексту: «Стерти» в Mii Maker і «Видалити» деінде, «платіжна карта» в eShop, «картка AR» в AR Games. Інакше в довіднику писало б одне, а на екрані стояло б інше.

**Чому саме одинадцять.** Переглядач довідників сам не знає, де лежить перекладений файл — таблицю шляхів і таблицю назв додатків доводиться дописувати у вільне місце всередині його коду. Того місця рівно 1064 байти, і одинадцять довідників займають 977. Дванадцятий коштує близько сотні — тож наступні чекають, поки знайдеться нове вікно. Додатки, для яких перекладу немає, показують свій рідний довідник, як і до мода.

Разом — **30 перекладених частин системи плюс одинадцять довідників**: Меню HOME, Налаштування системи, Mii Maker, Журнал дій, Посібник, Гра по завантаженню, екранна клавіатура, Список друзів, Камера, швидка камера, Звук, Здоров'я і безпека, Площа StreetPass Mii, Вибір Mii, Сповіщення, Ігрові записи, екран помилки, тексти системних помилок, інтернет-браузер, Nintendo eShop, аплет покупок eShop, Miiverse, публікація в Miiverse, 3DS Memo, аплет Circle Pad Pro, Перенесення даних, Nintendo Zone, Face Raiders, AR Games, налаштування amiibo.

**Що потрібно**

- Nintendo 3DS / 2DS **європейської (EUR) версії**
- встановлена **Luma3DS** (кастомна прошивка)
- SD-карта

## Встановлення

**1. Скопіюйте файли на SD-карту**

Вимкніть консоль, вийміть SD-карту, вставте її в комп'ютер. Розпакуйте архів і скопіюйте папку `luma` в корінь SD-карти — туди, де вже лежить папка `luma`. Комп'ютер спитає, чи об'єднати папки — погодьтеся. Наявні файли не постраждають.

Якщо ставите поверх 0.10.0 — просто дозвольте замінити файли.

Поверніть SD-карту в консоль.

**2. Увімкніть патчі в Luma**

Натисніть і **тримайте SELECT**, тоді увімкніть консоль. З'явиться синє меню налаштувань Luma.

Знайдіть рядок **`Enable game patching`** (сьомий згори), натисніть **A** — навпроти нього має з'явитися `(x)`. Натисніть **START**, щоб зберегти й перезавантажитися.

**3. Виберіть українську мову**

`Налаштування системи` → `Інші налаштування` → `Мова` → **Українська** → `OK`.

Це той пункт, де раніше було «Русский». Він завжди підписаний «Українська», тож ви його побачите, навіть якщо консоль поки що англійською.

Консоль перезавантажиться сама. Готово.

## Якщо щось пішло не так

**Інтерфейс лишився російським** — не увімкнено `Enable game patching` (крок 2). Ця галочка злітає після оновлення Luma — поставте її знову.

**У списку мов немає «Українська»** — файли скопійовані не в ту папку або консоль не європейська (EUR).

**Меню HOME не запускається** — видаліть **тільки** файл `luma/titles/0004003000009802/code.ips`. Це та правка, що перекладає назви додатків і банери; решта перекладу Меню HOME працює й без неї.

**Довідник не відкривається — екран завантаження, тоді виліт у меню HOME.** Видаліть перекладений довідник того додатка; консоль повернеться до свого:

| Довідник | Файл |
|---|---|
| Інтернет-браузер | `luma/titles/0004003000009B02/romfs/00009d02.bcma` |
| Налаштування системи | `luma/titles/0004003000009B02/romfs/00022000.bcma` |
| Гра по завантаженню | `luma/titles/0004003000009B02/romfs/00022100.bcma` |
| Журнал дій | `luma/titles/0004003000009B02/romfs/00022200.bcma` |
| Nintendo 3DS Камера | `luma/titles/0004003000009B02/romfs/00022400.bcma` |
| Nintendo 3DS Звук | `luma/titles/0004003000009B02/romfs/00022500.bcma` |
| Mii Maker | `luma/titles/0004003000009B02/romfs/00022700.bcma` |
| Площа StreetPass Mii | `luma/titles/0004003000009B02/romfs/00022800.bcma` |
| Nintendo eShop | `luma/titles/0004003000009B02/romfs/00022900.bcma` |
| Face Raiders | `luma/titles/0004003000009B02/romfs/00022d00.bcma` |
| AR Games | `luma/titles/0004003000009B02/romfs/00022e00.bcma` |

Якщо не відкривається **жоден** довідник — видаліть `luma/titles/0004003000009B02/code.ips` разом з файлами вище. Текст самого переглядача (`Назад`, `Збільшити`, `Зміст`) лишиться українським, а назва додатка над сторінкою й пункт мови повернуться до російських.

**Тексти помилок зникли, лишився самий код** — видалено `msg_romfs.bin`, але лишився `code.ips`. Ці папки видаляйте цілком: `luma/titles/000400300000C502` (екран помилки) і `luma/titles/000400300000BE02` (Miiverse).

**Якийсь застосунок не відкривається, а на верхньому екрані текст помилки** — видаліть із SD-карти папку цього застосунку і перезавантажте консоль. Решта перекладу працюватиме далі:

| Застосунок | Папка |
|---|---|
| Журнал дій | `luma/titles/0004001000022200` |
| Посібник | `luma/titles/0004003000009B02` |
| Список друзів | `luma/titles/0004003000009F02` |
| Вибір Mii | `luma/titles/000400300000D102` |
| Сповіщення | `luma/titles/000400300000A002` |
| Налаштування amiibo | `luma/titles/000400300000B902` |
| Площа StreetPass Mii | `luma/titles/0004001000022800` |
| Екран помилки | `luma/titles/000400300000C502` |
| Miiverse | `luma/titles/000400300000BE02` |
| Публікація в Miiverse | `luma/titles/000400300000BA02` |
| Аплет покупок eShop | `luma/titles/000400300000D602` |
| 3DS Memo | `luma/titles/000400300000F602` |
| Аплет Circle Pad Pro | `luma/titles/000400300000CD02` |
| Гра по завантаженню | `luma/titles/0004001000022100` |
| Екранна клавіатура | `luma/titles/000400300000D002` |
| Здоров'я і безпека | `luma/titles/0004001000022300` |
| Камера | `luma/titles/0004001000022400` |
| Звук | `luma/titles/0004001000022500` |

⚠️ Папки Гри по завантаженню, клавіатури, Здоров'я і безпеки, екрана помилки, 3DS Memo та аплета Circle Pad Pro видаляйте **цілком**, з усім вмістом. Вони читають свій `*_romfs.bin` просто з SD-карти: якщо прибрати цей файл, а `code.ips` лишити, титул перестане завантажуватись.

**Літери `i` замість `і`, `ε` замість `є`** — так і має бути. У шрифті консолі немає українських літер `і ї є ґ`, а замінити шрифт можна лише зміною системних файлів — мод цього навмисно не робить. Виняток — рядок з датою вгорі екрана: там шрифт свій, титульний, і в нього додано `Н` і `д` заради неділі.

**Назва досі російська в Журналі дій, Керуванні даними, eShop і Перенесенні даних** — ці чотири читають назви окремо від Меню HOME. У черзі.
